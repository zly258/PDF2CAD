Convert printed or exported PDF drawings into editable CAD DXF with native dimensions, symbol blocks and zero-garbled Chinese.

## Highlights

- Vector PDF / scanned image to editable DXF (GBK + `gbcbig.shx` national fonts)
- Native `DIMENSION`, weld / roughness / FCF / datum / table / hatch blocks with `INSERT` reuse
- True circle / arc reconstruction, centre-line rebuild from point clouds
- OCR: built-in RapidOCR (offline), optional PaddleOCR, or an LLM endpoint
- Bilingual GUI (English / 简体中文), language choice remembered
- Portable Windows build — no Python required

## Assets

| File | Contents |
|------|----------|
| `PDF2CAD-1.0.0-win64.7z` | Portable Windows build. Unpack with 7-Zip and run `PDF2CAD.exe`. |
| `PDF2CAD-1.0.0-source.7z` | Source code. |

## Requirements

- Windows 10/11 for the packaged build; Python 3.9+ when running from source.
